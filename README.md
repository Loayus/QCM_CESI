# QCM Trainer

## Récupérer le projet

```bash
git clone https://github.com/Loayus/QCM_CESI.git
cd QCM_CESI
```

## Lancer le site

```bash
python3 -m http.server 8000
```

Puis ouvrir http://localhost:8000 dans le navigateur.

(Une connexion Internet est nécessaire pour charger les polices et les bibliothèques.)
